# AquaPure SME Governance and Cybersecurity System

## Project Overview
A practical Python-based governance and cybersecurity system developed for a hypothetical Kenyan SME, AquaPure Water Solutions.

## Main Features
- User authentication and role-based access control.
- Data classification and governance register.
- Risk assessment and risk register.
- Security incident management and evidence recording.
- Incident closure and approval records.
- Compliance tracking.
- Audit logging and access-denial monitoring.
- Automated governance monitoring.
- Database backup and recovery.
- Consolidated Excel reporting and dashboard.

## Technology
- Python 3.14
- SQLite
- pandas
- openpyxl
- Windows PowerShell

## How to Run
1. Install Python.
2. Install dependencies using: pip install -r requirements.txt
3. Open the project folder in VS Code.
4. Run: python main.py
